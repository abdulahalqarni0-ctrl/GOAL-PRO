# GOAL PRO Web App

واجهة ويب عربية RTL متجاوبة ومهيأة كـ Progressive Web App (PWA) لتثبيتها على شاشة iPhone الرئيسية.

## تشغيل سريع على الآيفون
1. ارفع محتويات هذا المجلد إلى استضافة HTTPS ثابتة (مثل GitHub Pages أو Netlify).
2. افتح رابط الموقع في Safari على iPhone.
3. اضغط زر المشاركة في Safari.
4. اختر «إضافة إلى الشاشة الرئيسية» ثم «إضافة».

## الملفات
- index.html: الصفحة الرئيسية.
- styles.css: التصميم المتجاوب.
- app.js: التفاعلات والبيانات التجريبية.
- manifest.webmanifest: إعدادات PWA.
- sw.js: التخزين المؤقت للعمل دون اتصال بعد أول زيارة.
- icon.svg: أيقونة التطبيق.

## تنبيه مهم عن البيانات
المباريات والنتائج والإحصائيات الموجودة في app.js أمثلة تجريبية وليست نتائج حقيقية أو مباشرة. إدراج جميع دوريات العالم وتحديث النتائج الحقيقية يتطلب اشتراكاً في مزود بيانات كرة قدم مرخّص، وخادماً وسيطاً لحماية مفتاح API. لا تضع مفتاح API داخل JavaScript الذي يصل إلى المتصفح.

## النشر
يمكن نشر الملفات الثابتة على استضافة HTTPS. بعض ميزات PWA وService Worker لا تعمل من file:// أو من دون HTTPS.
